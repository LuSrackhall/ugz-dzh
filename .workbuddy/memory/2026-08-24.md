- **坑：Go encoding/xml 解析 r:id 必须写 `xml:"{URI}id,attr"` 的**空格形式** `xml:"URI id,attr"`**——前缀 `r:id` 和 `{URI}id` 都匹配不到（解析为空）。这是 Go xml tag 的命名空间语法（URI 空格 local）。
- **验证方法（可靠）**：总宽对比用 **XML cols 解析求和**（zipfile 读 sheet XML），不能用 excelize GetRows（裁剪空列）或 GetColWidth（零宽列失真）。9 个月全部 sheet 总宽 0 差异；行高总和/页面设置（size/orientation/scale/fitToW/H）/页边距 0 差异；期初/期末 sheet 天然一致（不重建）；全测试绿。
