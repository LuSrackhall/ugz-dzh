## 配置模板库 templates/（00:48，用户：多份默认配置供机器选用）

- **需求**：不同机器（屏幕缩放/WPS 版本差异）同一系数显示不同——把已验证的完美配置沉淀为模板库，其他机器可直接选用免微调。
- **实现**：skill 包加 templates/（print-config.win-standard.json = 当前默认标定 + mac-standard.json = Mac 默认）；SKILL.md 加"配置模板库"小节（清单/选用方法：cp 到输出根目录或 --config/贡献流程：交开发方入库随发版）。
- **验证**：两份模板 cp 后 generate 自动发现正常加载；全量测试 + test-e2e 过。
- **用户贡献流程**：win 机器标定完美后把 print-config.json 给开发 → 入库（命名带环境特征 + _comment 适用条件）→ 发版。
- **坑**：bash heredoc 与 `||`/`&&` 组合的 cat >> 会卡住后台任务——写文件用 Write/Edit 工具或单条命令，勿用 `cat >> f || mkdir && cat >> f << EOF`。
