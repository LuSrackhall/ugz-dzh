### 关键查证结论
- **财会〔2023〕14号《农村集体经济组织会计制度》= 唯一权威口径**：资产(101-181)/负债(201-241)/权益(301-322)/成本(401)/损益(501-521)，共 42 个一级科目。与用户提的 5 类完全一致。
- **现有 17 类 accountTypes 覆盖不足（真痛点，有数据佐证）**：e2e 真实账本 `专项应付款-日间照料中心` 被归"未分类"（内置表只有"应付款"，无官方 241 专项应付款）；累计折旧/在建工程/库存物资/短期投资/生物资产/应付工资/短期借款/应交税费/一事一议资金/收益分配/生产劳务成本/所得税费用等官方科目全部缺失。
- **分类口径差异**：现状"资产/负债/权益/收入/费用"5 类（收入费用分开）；官方"资产/负债/权益/成本/损益"5 类（损益合一）。报表/年结转需要"收入 vs 费用"区分 → 官方五类下用编码段位区分，不丢子维度。

### 设计稿要点（docs/account-code-design.md）
- **JSON schema 扩展（向后兼容）**：新增顶级 `科目编码表`（编码→名称/属性/大类/上级）；`科目树` 保持 key=全路径名称零破坏；节点加冗余 `科目编码`；旧账套读入按名称自动补码，补不到标"未归类"不阻断。
- **编码是存储主键，名称可改**：凭证仍写名称（人眼可读），解析后映射编码。
- **报表/结转改造**：资产负债表按大类；收支结余表 = 50x 收入累计 − 51x/52x 支出累计；年结转识别损益段位；账页排序默认=编码序（替代科目顺序手工配置）。
- **生成前定义工作流**：init 内置官方表 → subjects scan（新增，凭证→候选审核表 CSV）→ 表上确认（编码/方向/期初）→ subjects/opening import → generate。
- **generate 收紧**：未定义科目不静默添加——交互询问"是否登记"；非终端（agent）默认中止给指引；`--allow-new` 逃生。
- **自动识别机制去留**：保留代码不作默认（`AutoItems` 仅 --allow-new 或旧账套兼容路径用）。
- **分期 P0~P4**：P0 官方科目表常量+双查归类（低风险地基）→ P1 科目字典落 JSON + init 模板 + 自动补码 → P2 审核表加编码 + subjects scan → P3 generate 收紧 → P4 报表/结转按编码段位。P0/P1 先行，每次独立发版+全量 e2e。
