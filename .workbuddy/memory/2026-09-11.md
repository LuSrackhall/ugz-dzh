## v0.10.3：纯账页版独立目录 pdf/——默认双产出（用户设计）

- 用户反馈 v0.10.0 的 ledgerOnly 开关"有点影响"（改变打印版本体的方式不好）→ 改为**正交双产出**：
  - `print/{月}.xlsx` = **完整打印版**（账页+日记账+报表+期初期末表），**始终完整、不受配置影响**
  - `pdf/{月}.xlsx` = **纯账页版**（仅三类账页，位格同 print/）——供导出 PDF 成册；将来 PDF 能力落此目录
- 实现：PrintConfig 删 LedgerOnly 字段（写入无效果）；TransformToPrint 恢复完整语义；新增 TransformToPrintLedgerOnly(viewPath, outPath) (int, error)（变换+移除非账页）；cmd/generate.go 双调用；测试改造（完整版不删 sheet + 纯账页版删 3 张断言）。
- 实测：demo print/ 15 张（含残留 ledgerOnly:true 配置也不生效 ✓）+ pdf/ 7 张（4GL+2ML+1分离页）✓；e2e 脚本产出 pdf/ ✓。
- 文档：docs/print-config.md ledgerOnly 节改写为"纯账页版 pdf/"；commands.md 产物清单 + README 打印章节；CHANGELOG v0.10.3；SKILL bump 0.10.3 双目录同步。
