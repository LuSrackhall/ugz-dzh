# A4 横向总分类账布局参数设计

## 设计目标

为总分类账（总分类账）提供符合手工账格式的 A4 横向完整布局参数，可直接写入 `DefaultGLSpec()`。

## 物理参数

### 纸张

| 参数 | 值 | 说明 |
|------|-----|------|
| `PaperWidthMM` | 297 | A4 横向 |
| `PaperHeightMM` | 210 | A4 横向 |

### 装订边距与页间隙

正/反面同 Sheet 并排，正面（左）为奇数页，反面（右）为偶数页。

| 参数 | 值 (mm) | 说明 |
|------|---------|------|
| `LeftMarginMM` | 15 | 装订侧：正面左边距 = 背面右边距 |
| `RightMarginMM` | 15 | 装订侧：背面右边距（下一张纸的正面左边距） |
| `PageGapMM` | 8 | 正/反面之间的间隙（裁切侧） |

**推导：**
- 总可用宽度 = 297 - 15 - 15 - 8 = 259mm
- 每侧内容区宽度 = 259 / 2 = **129.5mm**

**有效边距：**
- 正面页：左装订边 15mm，右裁切边 ~4mm（PageGap 的一半）
- 反面页：左裁切边 ~4mm，右装订边 15mm

## 行结构

标题区（TitleRowCount = 4）+ 数据区：

| Excel 行号 | 索引 | 用途 | 高度 |
|-----------|------|------|------|
| 1 | TitleRow (0) | "总    分    类    账"（深绿 14pt 加粗双下划线） | 24pt |
| 2 | PageNumRow (1) | "分第 n 页" + "科目名称"（RichText 换行） | 36pt |
| 3 | (2) | 空行（视觉分隔） | 12pt |
| 4 | HeaderRow (3) | 列标题（深蓝灰背景，下边框） | 18pt |
| 5~24 | DataStartRow+0~19 (4~23) | 20 行数据 | 22pt |
| 25 | DataStartRow+20 (24) | "过次页"行（第 21 行数据） | 22pt |
| 26 | DataStartRow+21 (25) | "承前页"行（下一页第 1 行，标题前） | 22pt |

> 过次页与数据行同高，不特殊处理。承前页为下一页标题行之前的一行。

### 标题区列分割

- 行 1：`TitleSplitRatio = 0.5`，左 50% 写"总    分    类    账"，右 50% 留空（或写单位名称）
- 行 2：同一列分割，右 50% 写"分第 1 页\n科目名称"

## 列比例

以 129.5mm/侧为基础：

| # | 列名 | Ratio% | 宽度 (mm) | 说明 |
|---|------|--------|-----------|------|
| 1 | 日期 | 8 | 10.4 | 日期显示（如 "01-15"），后续可拆为"月"+"日" |
| 2 | 凭证号 | 9 | 11.7 | 如"记1"、"银收5" |
| 3 | 摘要 | 27 | 35.0 | 最宽列，容纳会计摘要 |
| 4 | 借方金额 | 16 | 20.7 | 格式化金额显示（#,##0.00） |
| 5 | 贷方金额 | 16 | 20.7 | 同上 |
| 6 | 方向 | 5 | 6.5 | "借"/"贷"/"平" |
| 7 | 余额 | 14 | 18.1 | 方向+格式化余额 |
| 8 | 金额分栏 | 5 | 6.5 | 金额分栏（数字逐位显示预留） |

**总计：** 8 + 9 + 27 + 16 + 16 + 5 + 14 + 5 = **100%**

### 金额分栏说明

"金额分栏"列作为金额分栏空间的预留位置，实际使用时分以下两种模式：

**模式 A（当前—简化）：** 金额以格式化数字写入各自列（借方金额、贷方金额、余额），"金额分栏"列暂不填充。

**模式 B（后续—分栏）：** 金额列（借方/贷方/余额）各拆分为 12 位数字栏 + 方向栏，补充 LayoutSpec 结构：
```
LayoutSpec 新增字段：
  AmountDigitCols int // 12（十亿~分）
  DirectionBeforeAmount bool // 方向栏在金额前，或金额后的最后栏
```
此时列比例调整为"金额分栏"类型列合并成一个总比例组，后续再针对组内拆分。

当前设计采用模式 A。

## 行高推导

数据行高度需容纳 12pt 字号 + 行间距：

| 元素 | 值 | 说明 |
|------|-----|------|
| 字号 | 10~12pt | 标准账表字号 |
| 行间距 | 2~3pt | 字高 67%~75% |
| 数据行高 | 22pt (~7.8mm) | 10pt 内容 + 上下间距 |
| 标题行高 | 24~36pt | 14pt 大字 + 间距 |

## 与当前 DefaultGLSpec 的差异对比

| 字段 | 当前值 | 新设计值 | 原因 |
|------|--------|---------|------|
| LeftMarginMM | 0 | 15 | 装订边 |
| RightMarginMM | 0 | 15 | 装订边（反面） |
| PageGapMM | 5 | 8 | 加宽正反面间隙 |
| 日期比例 | 10% | 8% | 减少，日期不需要太宽 |
| 凭证号 | 8% | 9% | 略增 |
| 摘要 | 25% | 27% | 增加，摘要需要更多空间 |
| 借方金额 | 15% | 16% | 略增 |
| 贷方金额 | 15% | 16% | 略增 |
| 方向 | 5% | 5% | 不变 |
| 余额 | 12% | 14% | 增加余额显示宽度 |
| 金额分栏 | 10% | 5% | 缩减为预留位 |
| TitleSplitRatio | 0.5 | 0.5 | 保持不变 |

## 验证

```go
spec := LayoutSpec{
    PaperWidthMM:      297,
    PaperHeightMM:     210,
    LeftMarginMM:      15,
    RightMarginMM:     15,
    PageGapMM:         8,
    TitleRowCount:     4,
    TitleSplitRatio:   0.5,
    ColHeaderRowCount: 1,
    DataRowsPerPage:   20,
    ColProportions: []ColProportion{
        {Name: "日期",     Ratio: 8},
        {Name: "凭证号",    Ratio: 9},
        {Name: "摘要",     Ratio: 27},
        {Name: "借方金额",  Ratio: 16},
        {Name: "贷方金额",  Ratio: 16},
        {Name: "方向",     Ratio: 5},
        {Name: "余额",     Ratio: 14},
        {Name: "金额分栏",  Ratio: 5},
    },
}
lay := ComputeLayout(spec)
// 正面区：129.5mm 宽 (297-15-15-8)/2
// 反面对称：129.5mm 宽
// 列宽度总和：129.5mm
```
