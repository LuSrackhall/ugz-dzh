# {year}.json 全字段说明（谁写谁读）

> `{year}.json` 是账本唯一权威源。字段分三类角色：**配置项**（人/agent 可改）、**工具账本**（generate 自动回写，勿手改）、**命令落点**（由对应命令写入）。
> 任何手工修改后：`ledger check` → 需要时 `generate -f` 重建 → git commit（见 SKILL.md git 纪律）。

## 顶层结构

```json
{
  "全局设置":   { "启动月": "...", "科目顺序": [], "科目映射表": {}, "合并总账科目": [],
               "总分类账忽略科目": [], "多科目明细账忽略科目": [], "结账月": "" },
  "科目树":     { "科目名": { "科目属性": "借|贷|未分类", "首次记录": {}, "余额": {} } },
  "自动识别科目": [ { "科目": "...", "首次月份": "...", "期初调整额": 0 } ],
  "手动调整科目": [ { "科目": "...", "生效月": "...", "期初调整额": 0, "说明": "..." } ],
  "明细列顺序":  { "总账科目": ["明细A", "明细B"] }
}
```

## 全局设置

| 字段 | 作用 | 谁写 | 状态 |
|---|---|---|---|
| `启动月` | 建账月，期初调整锚定月 | `init -s` | ✅ 核心 |
| `科目映射表` | OCR 错名 → 标准名，generate 时自动替换（总账/明细科目都匹配） | `ledger map` | ✅ |
| `合并总账科目` | 为父级科目生成合并 GL 帐页；**合并父级禁止直接记账/设期初** | 手工编辑 | ✅ |
| `总分类账忽略科目` | 父级下子科目不生成叶子 GL Sheet | 手工编辑 | ✅ |
| `多科目明细账忽略科目` | 父级下子科目不生成 ML Sheet | 手工编辑 | ✅ |
| `结账月` | ≤ 该月 generate 默认拒绝无 `-f`（防误改已结账月份） | `ledger lock -m`（`-m ''` 解锁） | ✅ |
| `科目顺序` | ⚠️ **当前版本未接线**：init 会生成空数组，但没有任何生成逻辑读取它。不要指望改它影响账本（后续版本决定实现或移除） | init | ⚠️ 遗留 |

三个忽略/合并字段可自由组合。例：三项全配 `["固定资产"]` → 固定资产只出合并帐页，叶子 GL 与 ML 均不生成。

## 科目树（工具账本，勿手改；唯一例外：科目属性）

| 字段 | 说明 |
|---|---|
| `科目属性` | `"借"` / `"贷"` / `"未分类"`。科目首现时按总账科目的内置类别自动推断（资产/费用→借；负债/权益/收入→贷；未知→未分类）。驱动期初/期末表的借贷分列。**属性指定入口：`ledger subjects import`（审核表「方向」列）** |
| `首次记录` | 方式/月份/金额——科目首现信息，工具维护 |
| `余额` | 按月 `{期初, 借方, 贷方, 期末}`——generate 后回写；是"上月期末→下月期初"余额链和月结"本年累计/本季累计"的数据源。**手改会被下次生成覆盖或引发 `check` 漂移告警** |

## 自动识别科目 / 手动调整科目

- `自动识别科目`：generate 时凭证中首次出现的科目自动追加（科目/首次月份）。`期初调整额`（元）可经 `add-manual` 或手工编辑设置。
- `手动调整科目`：`add-manual` / `subjects import`（0 期初登记）/ `opening import`（批量期初）的落点（科目/生效月/期初调整额/说明）。`生效月` **仅为信息性记录**，期初调整一律只作用于建账月（启动月）。批量入口：`ledger opening import -f 建账审核表.csv`（科目存在/属性一致/试算平衡三重校验，`--dry-run` 预演）。

## 明细列顺序（工具自动维护，可手工固定）

- 作用：多科目明细账（ML）各总账科目 Sheet 的**明细列顺序**。
- 新明细列出现时 generate 自动追加并回写；手工指定顺序后，generate 会校验与现有 Sheet 列结构的兼容性（冲突报错，不会静默错列）。

## 报表归类的真相（重要）

1. 资产负债表左右列、收支结余表归类：按**总账科目名精确匹配内置 17 类**——
   资产：库存现金/银行存款/应收款/内部往来/长期投资/固定资产；负债：应付款；权益：资本/公积公益金/本年收益；收入：经营收入/其他收入/投资收益/补助收入；费用：管理费用/公益支出/其他支出。
2. 不在 17 类内的总账科目 → 科目属性推断为"未分类"，资产负债表/收支结余表中**表底单列（不计入合计）**；期初/期末表按"未分类"处理。
3. **类别表目前硬编码在程序里，JSON 没有扩展类别字段**。实践守则：总账科目尽量选 17 类内的名字（明细科目任意）；确有自定义名，用 `ledger map` 映射到 17 类名（如 `办公用品费 → 管理费用`）。可配置类别表为后续版本待办（配合小企业会计准则预设）。

## 修改守则

- **可改**：全局设置（`结账月` 建议走 `lock` 命令）、科目属性、期初调整额、明细列顺序（明确知道自己在做什么时）
- **勿改**：科目树 `余额`/`首次记录`、`自动识别科目.首次月份`
- **改完必做**：`ledger check` → 视情况 `generate -f` 重建受影响月份 → git commit
