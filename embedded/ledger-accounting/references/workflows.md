# 凭证格式、红字、git 约定、报表说明

## 凭证格式（Markdown + HTML 表格）

每张凭证一个 `.md` 文件（文件名建议"记字第XXXX号.md"，便于重号检测）。必需要素：
- 日期行：`2025年12月20日` 或 `2025-12-20`
- 凭证号：`记字第0021号`
- HTML 表格 5 列：摘要 / 总账科目 / 明细科目 / 借方金额 / 贷方金额

示例：
```
# 2025年12月20日 记字第0021号
<table><tr><th>摘要</th><th>总账科目</th><th>明细科目</th><th>借方</th><th>贷方</th></tr>
<tr><td>购办公用品</td><td>管理费用</td><td>办公费</td><td>500.00</td><td></td></tr>
<tr><td>购办公用品</td><td>库存现金</td><td></td><td></td><td>500.00</td></tr>
<tr><td>合计</td><td></td><td></td><td>500.00</td><td>500.00</td></tr>
</table>
```
- 每行只填一方（借贷双填会提示可能使本月合计虚增）
- 合计行/表头行自动跳过
- 一次 generate 目录内所有凭证必须同一年同一月
- 同一凭证号不得出现在两个文件（重号告警）

## 红字（负数）表达

四种格式等价（统一解析为负数，即会计"同侧红字"语义）：

| 格式 | 示例 |
|---|---|
| 减号 | `-500.00` |
| 半角括号 | `(500.00)` |
| 全角括号 | `（500.00）` |
| 全角/Unicode 减号 | `－500.00` / `−500.00` |

- 红字在账页/日记账负数列示；打印版红色字体（#CC0000）
- 平衡校验按净额（借正贷负），如贷方红字 500 = 贷方 -500

## git 管理约定

**只 git 管**：手工凭证 md、`{year}.json`（权威源）、源码。
**不进 git**（派生产物，可重建）：xlsx 账本、`closing/` 结转凭证、`print/`。

推荐流程（每次记账后）：
```bash
git add 凭证目录 <年份>/<年份>.json
git commit -m "记账: 2025-10（新增科目 X / 期初调整 Y / 余额回写）"
```
- 新增科目、期初调整、余额回写都在 JSON diff 真实可见
- 跨年：year-close 生成新年 JSON 后同样提交

## 报表说明

- **资产负债表**：左=资产类期末；右=负债/权益类 + "本年收益（未结转损益）"（= 收入-费用，未结转时补行）；结转后"本年收益"科目入权益列；未分类科目表底列出（不计入合计）
- **收支结余表**：收入类累计（贷方）− 费用类累计（借方）= 本年收益
- **科目汇总表**：本月各科目借/贷发生额（合计借贷平衡）
- **凭证序时簿**：每凭证一行（日期/字号/摘要/借贷合计）
- **期初/期末表**：借贷分列试算平衡（借方合计 = 贷方合计）

## 年结完整流程（12 月末）

1. 12 月凭证记完 → `generate` 12 月（检查）
2. `gen-close` 生成结转凭证 → 打开 closing/ 核对金额
3. `generate 12月 -f`（自动并入结转，损益归零）
4. `check` 验证（无损益告警 + 期初平衡）
5. `year-close` 跨年（自动生成新年 JSON）
6. `lock -m 2025-12` 结账保护
7. git 提交（12 月 JSON + 新年 JSON）

## 常见科目（官方科目表，财会〔2023〕14号 42 个一级科目已内置）

资产：库存现金/银行存款/短期投资/应收款/内部往来/库存物资/消耗性生物资产/生产性生物资产/生产性生物资产累计折旧/公益性生物资产/长期投资/固定资产/**累计折旧**（贷余备抵）/在建工程/固定资产清理/无形资产/累计摊销（贷余备抵）/长期待摊费用/待处理财产损溢
负债：短期借款/应付款/应付工资/应付劳务费/应交税费/长期借款及应付款/一事一议资金/专项应付款
权益：资本/公积公益金/**本年收益**/收益分配
成本：生产(劳务)成本（期末余额=在产品，进资产负债表存货，年末不清零）
损益收入：经营收入/投资收益/补助收入/其他收入
损益支出：经营支出/税金及附加/管理费用/公益支出/其他支出/所得税费用

自创总账科目：属性"未分类"，不进报表合计、不参与年结转（`check` 有未分类统计提醒）——及时 `subjects import` 补属性或 `map` 映射到官方名。
