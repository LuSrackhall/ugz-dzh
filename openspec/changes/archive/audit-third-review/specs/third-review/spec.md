# third-review Spec

## ADDED Requirements

### Requirement: 合并父级禁止直接记账
`合并总账科目` 中的科目出现无明细直接分录时，generate 拒绝生成并报错提示使用子科目。

#### Scenario: 直接记账被拒
- **WHEN** 银行存款 在合并总账科目中，凭证含"银行存款"（无明细）分录
- **THEN** generate 报错"银行存款 为合并总账科目，请使用子科目（如 银行存款-工行）记账"

### Requirement: 期初不受合并视图污染
`ExtractLastMonthFinals` 跳过合并总账科目对应的 sheet（合并视图不进上月期末）；合并账期初只由子科目期初聚合（不叠加父级自身）。

#### Scenario: 合并父级期初不被污染
- **WHEN** 银行存款 为合并父级（子科目工行期初 3000），生成 2026-02
- **THEN** 银行存款期初=0（父级不作叶子）；合并账期初=子科目之和（3000）

### Requirement: 跨年结转校验
`year-close`：最近月非 12 月 → 告警；最近月期初借贷不平衡 → **告警不阻断**（与 generate 口径一致，避免历史数据卡死结转）；收入/费用类科目最近月末余额非 0 → 告警（疑似漏结转）。

#### Scenario: 损益科目漏结转告警
- **WHEN** 管理费用 12 月末余额 500（未结转），执行 year-close
- **THEN** 告警"管理费用 年末余额非 0，疑似漏结转"

### Requirement: 输入防线（双填/全角红字）
同行借贷双非零 → warning；全角括号 `（500）` 解析为负数。

#### Scenario: 全角括号红字
- **WHEN** 金额为 `（500）`
- **THEN** 解析为 -50000 分
