# design-review Spec

## ADDED Requirements

### Requirement: 现金/银行日记账
生成月度账本时输出 `现金日记账`（库存现金）与 `银行存款日记账`（银行存款及子科目）sheet：当月分录按日期逐笔排序，列日期/凭证号/摘要/对方科目/借方/贷方/余额；每日末行"本日合计"（日结）；月末"本月合计/本年累计/期末结存"；余额=期初+逐笔借-贷滚动；现金余额<0 时告警。

#### Scenario: 现金日记账日结月结
- **WHEN** 2025-10 有三笔库存现金分录（10-10 收30000 / 10-22 收20000 / 10-30 支6400），期初 0
- **THEN** 现金日记账逐笔列示，10-10 末"本日合计 借30000 余额30000"；月末"本月合计 借50000 贷6400 期末结存 43600"

### Requirement: 期初/期末表借贷分列
期初表/期末表按试算平衡口径：每行按科目属性分列（资产/费用→借方金额列，负债/权益/收入→贷方金额列）；表尾借方合计/贷方合计，不平衡显示差额。

#### Scenario: 期初表试算平衡
- **WHEN** 期初表含资产科目借 100000、负债科目贷 40000、权益科目贷 60000
- **THEN** 借方合计 100000、贷方合计 100000，平衡

### Requirement: year-close 生成新年度 JSON
`year-close` 自动将 `{year}.json` 复制为 `{year+1}.json`（同目录 `output/{year+1}/`）。

#### Scenario: 新年 JSON 自动生成
- **WHEN** 执行 year-close（2025→2026）
- **THEN** output/2026/2026.json 存在（科目树/配置/余额历史保留）

### Requirement: 损益结转凭证草稿
`year-close` 对损益类（收入/费用）科目期末余额非 0 的，输出结转建议分录（借：收入类科目余额 / 贷：本年收益；费用类反向，按余额方向）。

#### Scenario: 结转草稿输出
- **WHEN** 管理费用期末 500、其他收入期末 -300，执行 year-close
- **THEN** 输出"结转草稿：借 本年收益 500 / 贷 管理费用 500；借 其他收入 300 / 贷 本年收益 300"
