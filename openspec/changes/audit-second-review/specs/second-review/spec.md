# second-review Spec

## ADDED Requirements

### Requirement: 期初回退取最近期末（含 0）
`GetInitBalanceForGenerate` 从科目树回退取期初时，取**最近月份的期末余额（允许为 0）**；不得跳过期末=0 的月份回退到更早非零月份。

#### Scenario: 年末结平科目跨年不翻旧账
- **WHEN** 科目 X Balances：2025-11 期末=500、2025-12 期末=0，生成 2026-01（无上年 xlsx）
- **THEN** X 期初=0（取最近月 2025-12 期末），不因 2025-11 非零而错误回退

### Requirement: 红字金额格式解析
`parseAmountToCents` 支持四种负数书写格式并统一解析为负数：ASCII `-500`、括号 `(500)`、全角减号 `－500`、Unicode 减号 `−500`。

#### Scenario: 括号红字解析为负
- **WHEN** 金额单元格为 `(11,700.00)`
- **THEN** 解析为 -1170000 分（负数）

#### Scenario: 全角/Unicode 减号解析为负
- **WHEN** 金额单元格为 `－500` 或 `−500`
- **THEN** 解析为 -50000 分（负数）

### Requirement: 打印版红字红色字体标记
打印版金额拆位时，负数（红字）金额的数字用红色字体（#CC0000）标记；正数保持默认黑色。拆位仍按绝对值。

#### Scenario: 红字打印为红色数字
- **WHEN** 打印版某行贷方为 -11700.00（红字）
- **THEN** 该金额 12 小格数字填充 11700（绝对值）且字体为红色

### Requirement: 合并总账累计遍历全叶子
`WriteMergeGLClosings` 本年累计/本季累计汇总父级下**全部叶子科目**（含当月无分录但历史有累计者），与 GL/ML 口径一致。

#### Scenario: 无活动子科目计入父级累计
- **WHEN** 父级 F 下：A 1-4 月有分录（5 月无）、B 5 月有分录，生成 2026-05
- **THEN** F 本年累计 = A 的 ytd + B 的 ytd + 当月活动（A 的历史累计不被漏）
