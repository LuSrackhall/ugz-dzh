# voucher-balance Spec

## ADDED Requirements

### Requirement: 逐张凭证借贷平衡校验
凭证必须按（日期, 凭证号）分组逐张校验 `Σ|借方| == Σ|贷方|`（绝对值口径，兼容红字负数）。不平衡时 generate 拒绝生成，报错必须包含凭证标识（日期/凭证号）与差额金额。

#### Scenario: 平衡凭证通过
- **WHEN** 凭证 2026-01-05 记字第3号 共 2 行：借 500.00、贷 500.00
- **THEN** 校验通过，generate 正常继续

#### Scenario: 不平衡凭证被拒
- **WHEN** 凭证 2026-01-05 记字第3号：借 500.00、贷 300.00（差额 200.00）
- **THEN** 校验返回错误，报错含凭证号 3 与差额 200.00，generate 拒绝生成

#### Scenario: 红字按绝对值口径校验
- **WHEN** 凭证含红字：借 500.00、贷 -500.00（红字冲销）
- **THEN** |借|合计=|贷|合计=500，校验通过；红字行产生 warning 提示

### Requirement: 红字明确负数列示
借方或贷方金额为负数（红字）时：不自动修改金额（不折入对侧），校验通过后保持负数，账本/汇总中显示为负金额，并输出 warning 提示用户。

#### Scenario: 红字提示且不修改
- **WHEN** 某行贷方 -500.00（红字），凭证绝对值平衡
- **THEN** 该行 CreditCents 保持 -50000 不变，返回 warning"红字将显示为负金额"

### Requirement: 凭证号未解析保护
VoucherNum<=0 的条目无法可靠分组，跳过平衡校验并输出 warning（解析问题由 parser 另行告警），不得误并入其他凭证分组。

#### Scenario: 未解析凭证号跳过分组校验
- **WHEN** 某条目 VoucherNum=0（解析失败）
- **THEN** 该条目不参与分组平衡校验，产生 warning 提示"凭证号未解析，跳过平衡校验"
