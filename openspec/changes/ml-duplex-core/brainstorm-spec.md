## Context

多科目明细账（ML）需要非对称跨页布局以满足双面打印要求。Excel 中 Front 列区对应物理纸正面，Back 列区对应物理纸反面，同一逻辑页 = 上一张纸的反面(Back区) + 下一张纸的正面(Front区)。

DefaultMLSpec（12列/区）已在变更 4 中合入 main。

## 物理纸与 Excel 映射

```
打印顺序：
  ① 纸1正面(空白占位) → 翻面 → ② 纸1反面 + ③ 纸2正面 → 翻面 → ...

Excel Sheet:
← Front列区(正面) → |Gap| ← Back列区(反面) →

Row 0~3: 纸1正面空白占位表（明细帐标题、科目名称、分第1页右、列标题）
Row 4~23: 20行空白占位间距

Row 24~27: 逻辑页1标题 → Front=纸2正面标题, Back=纸1反面标题
Row 28~47: 逻辑页1数据(20行) → Front=明细5~14, Back=7基础+明细1~4

Row n~n+3: 逻辑页2标题 → Front=纸3正面标题, Back=纸2反面标题
Row n+4~n+23: 逻辑页2数据(20行)

最后一行: Back区=纸N反面空白占位, Front区=空
```

## Goals / Non-Goals

**Goals:**
- ML Sheet 按跨页布局写入：Front区(纸正面) + Back区(纸反面)
- 纸1正面空白占位表（带标题，20行间距）
- 同一条分录的基础列+明细1~4 写 Back区，明细5~14 写 Front区
- 首张空白占位、末张空白收尾
- 双下划线标题样式

## Decisions

### 决策 1：列区分配

使用 `DefaultMLSpec()`（nCol=12，Front/Back 各 12 列）：
- Back 区（反面列）：0~6=7 基础列, 7~10=明细1~4
- Front 区（正面列）：0~9=明细5~14
- 两个区都有额外列留空

### 决策 2：纸1 空白正面

第一篇 Sheet 初始写入时，在 Front 区写入空白占位表（标题行 + 20行间距）。
纸1 反面的 Back 区留空。后续逻辑页正常写入两区。

### 决策 3：数据写入

`appendToMLSheet` 重写：每次写入同时写 Back 区（7基础+4明细）和 Front 区（10明细）。

### 决策 4：过次页/承前页

同时写入两区。过次页后→标题区→承前页。

## Risks / Trade-offs

| 风险 | 缓解 |
|---|---|
| 纸1 空白正面占用 24 行（标题+20间距），压缩 Sheet 有效空间 | 一次性占位，后续逻辑页正常 |
| 结尾纸N 反面空白占用 | 加末尾空白检查 |
| DefaultMLSpec 的 nCol=12 超出列宽限制 | 装订列+RightMargin 有足够余量 |
