## Context

多科目明细账（ML）的正反面布局与总分类账（GL）根本不同。GL 的正反面完全对称（正面=Front 区的 7 列数据，反面=Back 区的 7 列数据），ML 则是非对称跨页布局：

```
纸张1 正面(空白占位) → 确保打印对齐
纸张1 反面 → 逻辑页1 左半 (Back区: 7基础列+4明细)
                  ↓ 横向上同Excel Row
纸张2 正面 → 逻辑页1 右半 (Front区: 10明细+标题/页码)
纸张2 反面 → 逻辑页2 左半
纸张3 正面 → 逻辑页2 右半
```

逻辑页 1 = 纸张1 反面 (左) + 纸张2 正面 (右)。同一条分录的 14 个明细列分布在左 4 + 右 10，写在同一 Excel Row 的两个区域。

## Goals / Non-Goals

**Goals:**
- 实现 ML 跨页布局：奇偶页不再简单交替，而是逻辑页的左/右半
- 同一 Row 写入 BackStartCol 区（7基础+4明细）+ FrontStartCol 区（10明细）
- 左半（Back 区）有：科目名称、分第 N 页(左)、列标题（7基础+4明细）、承前页/上年结转、数据行
- 右半（Front 区）有：明细帐标题、科目名称、分第 N 页(右)、列标题（10明细）、数据行
- 双下划线横跨整个跨页
- 首张正面空白占位，打印后对齐
- 20 行数据/逻辑页（承前页/上年结转列入计数）
- 页码标注：分第 N 页(左)、分第 N 页(右)

**Non-Goals:**
- 不改 GL 正反面布局
- 不改 LayoutSpec（现有 Front/Back 坐标不变，但 ML 的列分配方式不同）

## Decisions

### 决策 1：数据写入方式

同一行分录的 14 明细列同时写入 Back 区（明细 1~4）和 Front 区（明细 5~14）。基础列（日期~余额）只在 Back 区。

写入时不分奇偶页——每行数据总是同时写到两个区。过次页/承前页也写两区。

### 决策 2：标题区位置

左半（Back 区顶部）：
- 科目名称
- 分第 N 页(左)
- 列标题（7基础列头 + 4明细列头）

右半（Front 区顶部）：
- 明 细 帐（固定标题）
- 科目名称（与左半同一 Row）
- 分第 N 页(右)
- 列标题（10明细列头）

### 决策 3：首张正面空白占位

第一张纸的正面（逻辑页 前）创建空白 Sheet 或空行，确保第一张反面与第二张正面的数据行横向对齐。

### 决策 4：双下划线

从 Back 区左边界到 Front 区右边界的双下划线。跨页整体绘制（一行 Cells 带顶部双线边框）。

### 决策 5：生成流程

ML 的 `appendToMLSheet` 重写为：
1. 创建或复用 Sheet
2. 写标题区（左右两侧）
3. 写数据行（同时写两侧）
4. 满 20 行→过次页（同时写两侧）
5. 翻页→新标题区

## Risks / Trade-offs

| 风险 | 缓解 |
|---|---|
| 同一 Row 写两个区域，PageGap 列被跳过 | 两区之间有 Gap 列，不写入数据 |
| 首张空白正面浪费空间 | 这是一次性占位，后续逻辑页正常 |
| 打印时需对齐左右半 | 严格按相同 Row 号写入，Excel 打印选区控制 |
