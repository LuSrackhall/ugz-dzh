## Context

本项目是手工账电子化生成系统，输入按月整理的凭证 Markdown 文件和全局 JSON 配置，生成 Excel 工作薄。当前输出只有一个查看版 xlsx，其行列坐标通过硬编码常量（如 `printGLColDate = 1`）控制。

随着对打印输出还原度的要求提高（双下划线、金额分栏、奇偶页布局、过次页/承前页、正/反面同 Sheet），硬编码方式无法满足需求——任何列宽/行高调整都需要修改多处写入逻辑，容易破坏布局。

设计过程中曾考虑 HTML 输出方案，但最终决定**纯 Excel 方案**，通过代码控制所有行列坐标，不依赖 Excel 页眉/页脚/边距功能。

## Goals / Non-Goals

**Goals:**
- 建立一套物理驱动、Spec 驱动的布局计算架构（LayoutEngine），所有行列坐标通过 `ComputeLayout(spec)` 计算
- 正/反面页内容并排在同一个 Sheet，打印时选区打印
- 每页结构：标题区（分第 n 页、总分类账、科目名称）+ 列标题 + 数据区（含过次页/承前页）
- 标题文字样式：深绿双下划线、印章红科目名称、分第 n 页绿色配红色 n
- 支持后续任意列拆分/增加（如日期→月/日、金额位数变化）不破坏布局

**Non-Goals:**
- 不依赖 Excel 页眉/页脚做样式
- 不依赖 Excel 镜像边距功能（由空列模拟）
- 不涉及多科目明细账的布局（后续单独设计）

## Decisions

### 决策 1：纯 Excel 方案，不做 HTML

**选择**：纯 Excel 方案

**理由**：所有数据计算逻辑已在 Excel 写入器中（余额、分页、月结），纯 Excel 方案可复用现有逻辑，无需额外验证一致性。HTML 需要提取中间数据层，重构成本高。

**替代方案**：HTML 方案（放弃），混合页眉方案（放弃）

### 决策 2：代码逐页写标题，不用打印重复行

**选择**：不用 Excel 打印标题行功能，每次过次页后由代码写入新页的标题行（分第 n 页、科目名称等）

**理由**：打印重复行内容固定，无法显示逐页变化的页码；也无法在奇偶页切换科目名称的位置。纯代码写入可以完全控制每页内容和样式。

### 决策 3：物理单位驱动，不硬编码列号

**选择**：以 mm 为单位定义页面物理约束，`ComputeLayout(spec)` 计算所有坐标，渲染器只消费坐标

**理由**：后续日期列拆为月/日两列、金额位数变化时，只需修改 Spec 的比例字段，所有坐标自动重算，不破坏其他区域。

**替代方案**：继续硬编码列号（放弃——每次变更需全局返工）

### 决策 4：正/反面内容同 Sheet 并排

**选择**：正面在左、反面在右，中间用空列隔开，打印时分别选区打印

**理由**：用户需求明确指出"正面左边距大、反面右边距大"，并排在同一 Sheet 可以精确控制正反面样式，支持单面打印机的操作。

### 决策 5：页边距由空白行列模拟

**选择**：Excel 页边距设为最小值，装订边、页间隙由空列模拟

**理由**：Excel 的镜像边距功能在实际使用中可能受限（打印机驱动不支持），且页眉区域无法做虚线下划线。空列方案完全脱离 Excel 限制。

## Risks / Trade-offs

### [正/反面选区打印操作不便] → 提供操作指引
用户需要分别选中左右区域打印，初次使用可能不熟练。通过 README 提供步骤说明。

### [行列映射复杂度] → 单一入口 ComputeLayout
所有行列映射集中在 `ComputeLayout` 函数，不分散到各渲染代码。

### [Spec 配置项过多] → 渐进完善
Spec 初期只包含必要字段（纸张尺寸、装订边、每页行数），其余按需添加。
