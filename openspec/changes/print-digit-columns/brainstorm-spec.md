# 打印版位格输出（print-digit-columns）设计文档

## Context

现有系统每月生成查看版累计工作薄 `{output}/{year}/{year}-MM.xlsx`，其中 GL（总分类账，含 MergeGL 合并总账）、ML（多科目明细账）的金额以 `#,##0.00` 数字格式写在单个单元格中。真实手工账使用人民币位格（小格分位）书写金额。

本变更新增**打印版**输出到 `{output}/{year}/print/{year}-MM.xlsx`：版面编排、纸张尺寸、行列结构、标题区等与查看版完全一致，唯一区别是金额栏所在列平均拆分为 12 个小列，数字按人民币位拆分填入。

用户已确认的关键决策：
1. 页面编排不变（正反并排、尺寸全部一致），仅金额栏拆 12 小列
2. 金额恒为正值显示——余额正负由「借或贷」方向列表达（会计准则），明细净额为负时取绝对值填格
3. 转换范围：GL + MergeGL + ML 三类账页；期初/期末汇总表不动
4. 大标题（借 方 / 贷 方 / 余 额 等）跨 12 小列合并
5. 实现方式：方案 A「生成后转换副本」（读已落盘的查看版 xlsx → 内存改写 → 另存打印版）
6. 表头边框按分段规则改造，标题区合并随之调整
7. 计算逻辑共用；打印版样式代码独立成文件降低耦合
8. 用户授权 AI 自行决策其余细节

## Goals / Non-Goals

**Goals:**
- 新增打印版 xlsx 输出到 `{output}/{year}/print/{year}-MM.xlsx`
- GL/MergeGL/ML 所有金额列（GL 借/贷/余额；ML 借/贷/余额/明细1-14）拆为 12 小列，总宽守恒
- 小列表头「十 亿 千 百 十 万 千 百 十 元 角 分」写入现有表头区空位行（不新增行）
- 分组边框：加粗线在 十亿|亿、百万|十万、千|百 组界；红色单细线在 元|角；其余普通绿色细线
- 查看版代码路径零改动，查看版输出字节级不受影响
- 打印版样式代码独立成新文件

**Non-Goals:**
- 不修改查看版 xlsx 的任何内容或生成逻辑
- 不引入 HTML/PDF 等其他打印格式（记忆：no-print-versions 已被本次需求推翻，但仅限 xlsx 位格化）
- 不改变期初表/期末表/CSV 等辅助 Sheet
- 不做打印预览功能

## Decisions

### D1: 生成后转换副本（方案 A）

`GenerateWorkbook` 完成 `wb.Save()` 落盘后，新增 `ConvertToPrint(viewPath, printPath)`：
1. `excelize.OpenFile` 重新打开刚落盘的查看版文件（内存副本，不影响磁盘上的查看版）
2. 对每个账页 Sheet 执行位格化转换
3. `SaveAs` 到 `{output}/{year}/print/{year}-MM.xlsx`

理由：铁律一零风险（查看版先落盘再转换）；计算逻辑天然复用；失败不影响主流程。
备选方案 B（独立重渲染整套账页）因需维护第二套渲染器被否决；方案 C（文本模拟位格）无真实竖线分隔被否决。

### D2: 插列法实现位格

对每个金额列右侧插入 11 列（原列成为第 1 小列「十亿」位），逐 Sheet **从右往左**插列，坐标基于原始 Layout 常量预计算：
- GL 每面 3 个金额列（借 glColDebit=5、贷 glColCredit=7、余额 glColBalance=10），Front/Back 各一套
- ML Back 侧 3 个金额列 + 明细1-4，Front 侧 明细5-14

已核实 excelize v2.10.1 源码：
- `InsertCols` 自动平移合并单元格（adjust.go adjustMergeCells）、单元格坐标、列宽定义 ✅
- `InsertCols` **不平移分页符**（源码 TODO: adjustPageBreaks）→ 需手动修复（见 D5）

### D3: 拆位规则 splitCNY(cents) → [12]string

- 从左到右 12 格 = 十亿 亿 千 百 十 万 | 千 百 十 | 元 角 分（个位结构性对齐「元」）
- 金额恒按非负处理：余额已有方向列；ML 明细净额为负取绝对值
- 金额为 0 时 12 格全留空（手工账惯例）；空金额格保持空
- 数字以字符串居中写入，小号字体（约 6~7pt 常量可调，74% 缩放下 11pt 放不进小格）
- 原金额格数值清空

### D4: 表头与小列表头

- **GL**（两行表头 HeaderRow/SubHeaderRow）：大标题「借 方」「贷 方」「余 额」由单列改为跨 12 小列合并（Unmerge 原 1 列纵向合并 → 重 Merge 为 12 列 × 2 行区域中小标题占上行的对应形式）；✓ 列、摘要、借或贷不动；小列标签行写入 SubHeaderRow 的金额区（该行金额区原本留空，只有月/日/字/号占用前 4 列）
- **ML**（四行表头 h1-h4）：借/贷/余额原 h1:h3 纵向合并扩展为 12 列宽矩形合并；明细科目名 h2:h3 合并扩展为 12 列宽；小列标签写入 h4 行（原本整行在金额列下方留空）；Paper1 占位页同样处理
- 「( )方金 / 额 分析」金额分析表头随其下明细列拆分同步扩展合并区

### D5: 结构副作用修复

- **分页符手动重建**：GL 垂直分页符右移 33 列（3 金额列 × 11）；ML 右移 77 列（7 金额列 × 11）。水平行分页符不受插列影响
- **列宽**：读原宽 W 后设 12 个小列各 W/12（总宽守恒）
- 合并单元格平移后需验证 ML 标题区（科目名合并横跨明细12-13，位于插列区内）：先 Unmerge 再按新坐标重新 Merge，不依赖 excelize 的自动平移结果

### D6: 数据行边框派生算法

遍历数据区每一行的每个原金额格：
1. 读原格样式（GetStyle）
2. 第 1 小格继承原左边框语义（如金额栏红色双线）、第 12 小格继承原右边框语义
3. 中间 10 条竖线替换为绿色细线；上下边框（每 5 行加粗、过次页红双线底边）原样复制到全部 12 小格
4. 字号替换为小列字体，保留数字格式清除（改写字符串）

装饰性边框（表头顶部红双线、外侧边缘红双线、月结加粗等）零丢失。

### D7: 分组边框常量表

```
分隔位置（12 格之间共 11 条竖线）:
格1|格2   加粗（亿|十亿组界）
格2|格3   普通
格3|格4   普通
格4|格5   加粗（万|十万组界，即 百万位|十万位）
格5|格6   普通
格6|格7   加粗（千|百组界，即 千位|百位）
格7|格8   普通
格8|格9   普通
格9|格10  红色细线（元|角）
格10|格11 普通
格11|格12 普通
```
加粗=绿色 Style 2（与现有每5行加粗一致），红细线=CC0000 Style 1，普通=006100 Style 1。

### D8: 文件划分与调用点

```
generator/print_convert.go  入口 ConvertToPrint + splitCNY + 分组边框常量表 + 样式派生工具
generator/print_gl.go       GL/MergeGL 表头几何与转换流程
generator/print_ml.go       ML 四行表头几何与转换流程（含 Paper1 占位页）
cmd/generate.go             GenerateWorkbook 成功后调用 ConvertToPrint；
                            -f 级联删除同步清理 print/ 子目录中大于当月的文件（现有级联只清根目录，是缺口）
```

失败策略：打印版生成失败仅向 stderr 打印告警，不中断 generate 主流程（铁律三：xlsx 是生成品）。

### D9: Sheet 识别

前缀判断：`总分类账-`（天然覆盖 MergeGL，二者同前缀同格式）与 `多科目明细账-`。期初表 `{month}期初`、期末表等不动。

## Risks / Trade-offs

- [InsertCols 在复杂 Sheet 上行为] → e2e 生成多月数据后抽查：列数、样本数字位、合并区数量、分页符位置；转换器内对关键坐标断言
- [总宽 ÷12 的渲染微漂移]（Excel 列宽单位非严格线性）→ 接受亚毫米级误差；若打印偏移再调补偿常量
- [富文本年份、印章样式等特殊单元格被平移后样式错乱] → 转换后遍历表头区抽查；必要时对表头区重建样式而非依赖平移
- [小格字号过小不可读] → 字号为常量，实机打印一次即可校准
- [打印版与未来查看版布局演进脱节] → 转换器只依赖 layout 包公开常量，Layout 变更时编译期暴露失效

## 验证计划（宪法 1.5）

1. 单元测试：splitCNY 表驱动（0、1分、5元、99999999.99、负数取绝对值）；分组边框表完整性
2. `go test ./...` 全绿
3. `bash scripts/test-e2e.sh --skip-test` 多月生成 → 抽查 print/{year}-MM.xlsx：
   - GL/ML Sheet 数与查看版一致
   - 金额列数 = 原列数 × 12
   - 样本分录数字各位正确、0 留空
   - 合并区数量与位置符合预期
   - 分页符位置正确（垂直分页符右移后仍落在书口/装订区前）
   - 查看版文件 mtime 与内容未被触碰
4. 打开 xlsx 目检表头分组边框与整体版面
