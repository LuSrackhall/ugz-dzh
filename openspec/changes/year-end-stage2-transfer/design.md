# 设计：年末二段结转

## D1 触发方式：默认自动 + `--no-transfer` 逃生

二段默认随 gen-close 自动生成，`--no-transfer` 显式跳过。

理由：制度要求年末两段齐做，默认不做等于把本变更要修的缺陷留在默认路径上；closing/ 是派生产物（不进 git、可幂等重建），误做删除重跑即可，风险面与 gen-close 现有"自动预登记科目"的自洽哲学一致。

## D2 金额重算与防重口径

**postFinal（第一段并入后本年收益的有符号余额，借正贷负）**：

```
postFinal = Tree[本年收益].Balances[month].Final（缺失按 0，用 FinalAtOrBefore 回退）
          + Σ 全部收入/费用科目 Balances[month].Final
```

求和**不排除已在 closed map 里的科目**——这是刻意的，覆盖三种运行态且结果同值：

| 运行态 | Tree[本年收益].Final | Σ损益 Final | postFinal |
|---|---|---|---|
| 干净首跑（未生成结转） | 0 | -net | -net ✓ |
| 一段已并入 closing/ 尚未 generate 合并 | 0 | -net | -net ✓ |
| 一段已 generate 合并（老版本升级账套） | -net | 0 | -net ✓ |

**hasTransfer（二段已做过）**：扫描 `closing/*.md` 解析分录，任一分录的总账科目段 == "收益分配" 即 true。不能用"本年收益出现过"判定（一段凭证本身就含它）；收益分配在制度上只应出现在二段，误报面为零。目录按年隔离（`output/{year}/closing/`），跨年自然不串。

**触发条件**：`!noTransfer && !hasTransfer && postFinal != 0`。早退条件相应放宽：一段无待结转科目但二段仍需生成时，不早退（只写二段凭证）。

## D3 明细层级：挂明细"收益分配-未分配收益"（推荐）

制度 322 收益分配 使用说明明确"应设置'各项分配''未分配收益'明细科目"，年末结转官方口径即记入未分配收益明细。挂明细的理由：

1. **制度忠实**：凭证 总帐科目=收益分配 / 明细科目=未分配收益，与官方分录逐字对应；
2. **报表对应**：资产负债表权益行显示"收益分配-未分配收益"，与官方报表项目"未分配收益"一一对应；
3. **零迁移**：段③（各项分配，次年功能）落地时无需重分类——若挂总账，届时须一张凭证把父级直挂余额挪进明细；
4. **系统惯例一致**：真实账套科目树只定义叶子全路径，"收益分配-未分配收益"就是一个叶子，登记/期初/报表/GL 账页全链路天然支持。

代价可忽略：GL sheet 名较长；科目余额表多一行父级合成汇总行（既有父子汇总设计的正常行为）。

备选（不采用）：挂总账"收益分配"——少一个树节点，但制度偏差 + 未来迁移成本。

## D4 资产负债表权益列：零改动（推演固化）

writeBalanceSheet 现行逻辑（收入/费用不入列 → yearProfit 行；负债/权益按科目行列示，贷余为正、借余红字负）在各月态下均正确：

| 月态 | 权益列表现 |
|---|---|
| 未结转月（年内普通月） | "本年收益（未结转损益）"行 = 当年累计净额 |
| 已结转月（12 月二段合并后） | 收入/费用 Final=0 → yearProfit 行消失；结转目标科目按贷余显正数（净亏损借余红字负） |
| 混合年（有结转历史 + 当年未结转） | 两行并存，数值各自正确 |

结论：不改 report_sheets.go，用 e2e 断言固化三种月态。收支结余表不涉及（结转目标科目是权益类，不进收支行），不动。

## D5 凭证规格

- 文件名：`记字第%04d号 年末收益结转.md`（与一段"年末损益结转"区分，防重扫描双保险）；
- 摘要：`年末收益结转`；
- 日期：余额月最后一天（与一段一致，同月才被 generate 并入）；
- 编号：一段占用 existing+1，二段顺延 existing+2（一段被跳过时二段取 existing+1）；
- 分录：单借单贷，金额=|postFinal|，方向按 D2 符号（贷余→借本年收益/贷目标；借余→借目标/贷本年收益）；
- 科目登记：目标科目缺失时 AddManualAdjustment(StartMonth, 0, 自动登记) + SetAccountProperty("贷")，SaveConfig 落盘后才写凭证（先定义后生成，避免自锁）。
